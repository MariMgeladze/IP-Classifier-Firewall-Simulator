#  IP Classifier & Firewall Simulator

ეს არის კიბერუსაფრთხოების კურსის საფინალო პროექტი, რომელიც შედგება ორი ძირითადი მოდულისგან: 
**IP მისამართების კლასიფიკაცია** და **ფაირვოლის სიმულატორი**.

##  ფუნქციონალი

### 1. IP Classifier (`block1.py`)
- IPv4 მისამართის ფორმატისა და სტრუქტურის ვალიდაცია.
- IP მისამართის კლასის დადგენა (Class A, B, C, D, E) პირველი ოქტეტის მიხედვით.
- Private vs Public IP მისამართის ტიპის განსაზღვრა (RFC 1918 სტანდარტით).



### 2. Firewall Simulator (`block2.py`)

სიმულატორი Packet Filtering Firewall-ის პრინციპზეა აგებული: მომხმარებლის მოთხოვნას (IP, პორტი, პროტოკოლი) წესების სიასთან ადარებს და წყვეტს, **ALLOW** იქნება თუ **DENY**.

**როგორ მუშაობს:**
- მომხმარებელს შეჰყავს პორტი, პროტოკოლი (TCP/UDP) და IP მისამართი. ყოველი მათგანი მოწმდება (არასწორი მონაცემების შეყვანისას პროგრამა წყდება)
- IP მისამართის ტიპი (Private/Public) განისაზღვრება RFC 1918 დიაპაზონებით
- წესები მოწმდება ზემოდან ქვემოთ, პირველი დამთხვევა წყვეტს შედეგს (**First Match**)
- თუ არცერთი წესი არ ემთხვევა, მოთხოვნა იბლოკება (**Default Deny**)

**წესები:**

| # | IP ტიპი | პორტი | პროტოკოლი | მოქმედება |
|---|---|---|---|---|
| 1 | any | 23 (Telnet) | TCP | DENY |
| 2 | Private | 22 (SSH) | TCP | ALLOW |
| 3 | Public | 22 (SSH) | TCP | DENY |
| 4 | any | 80 (HTTP) | TCP | ALLOW |
| 5 | any | 443 (HTTPS) | TCP | ALLOW |
| 6 | any | 53 (DNS) | UDP | ALLOW |

**შეზღუდვები:** სიმულატორი ამოწმებს ერთ მოთხოვნას გაშვებაზე, არ იმახსოვრებს კავშირებს (stateless) და არ აანალიზებს პაკეტის შიგთავსს.

## გაშვება

```
python block1.py   # IP კლასიფიკატორი
python block2.py   # Firewall სიმულატორი
```
